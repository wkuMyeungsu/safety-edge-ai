Pi에 연결하는 방법

Pi는 한 대이고, Pi 관리자(명수)가 관리한다. 팀원은 아래 세 가지 방법으로 Pi를 쓴다.

현장 ESP32Pi와 같은 LAN

  • 사진을 보낼 때는 위의 두 줄을 쓴다. 3절에서 설명한다.
  • 코드를 바꿔서 시험할 때는 마지막 줄을 쓴다. 4절에서 설명한다.
  • 인터넷에는 gateway 하나만 열려 있다. SSH 같은 다른 접속은 막혀 있다.
3

사진 보내기

보내는 네트워크에 따라 주소가 다르다. 외부 네트워크에서 보낼 때는 토큰이 꼭 필요하다.

보내는 곳주소토큰
Pi와 같은 LANhttp://<Pi IP>:8001/frame필요 없음
외부 네트워크https://<Pi 이름>.<tailnet>.ts.net/frameX-Device-Token 헤더에 넣는다

토큰이 필요한 이유

  • Funnel 주소는 인터넷에 공개되어 있다. 주소만 알면 누구나 사진을 보낼 수 있다.
  • 모르는 사람이 보낸 사진도 그대로 판정되고, 위반이면 Supabase와 웹에 가짜 기록이 남는다.
  • 사진이 많이 들어오면 대기 줄이 차서 팀 ESP32의 사진이 503으로 거절된다.
  • 그래서 외부에서 온 요청은 팀 토큰이 있을 때만 받는다.
  • 같은 LAN은 Pi와 같은 네트워크에 있는 장치만 접근할 수 있어서 토큰을 검사하지 않는다.

PC에서 사진 한 장을 보내 보는 예시다.

curl -H "X-Device-Id: test-<이름>" -H "X-Device-Token: <토큰>" -H "Content-Type: image/jpeg" \
     --data-binary @사진.jpg https://<Pi 이름>.<tailnet>.ts.net/frame
  • 성공하면 202와 함께 사진 번호 frame이 돌아온다.
  • 토큰이 없거나 틀리면 401이 돌아온다.
  • 장치 ID는 ESP32면 cam-<이름>, 시험용이면 test-<아무거나>로 쓴다.
  • 토큰은 Pi 관리자에게 개인 메시지로 받는다. 저장소에는 올리지 않는다.
  • 실제 주소와 응답 형식은 api-manual.html에 있다.
4

내 코드를 Pi에 올리기

GitHub에서 Actions → deploy-pi → Run workflow를 누른다. 올릴 브랜치를 고르고, 아래 셋 중 하나를 고른다.

고르는 것하는 일
deploy내 브랜치를 Pi에 올린다. 그 뒤 30분 동안은 다른 사람이 올리지 못한다.
status아무것도 바꾸지 않고, 지금 Pi 상태와 최근 로그만 본다.
release시험이 끝났다고 알린다. 다른 사람이 다시 올릴 수 있게 된다.
  • 다른 사람이 시험 중이면 바로 실패한다. 실행 화면 맨 위에 누가 쓰고 있는지 나온다.
  • 시험이 끝나면 release를 누르고, dev를 다시 올려 둔다.
  • 모델 파일과 .env는 이 버튼으로 바뀌지 않는다. 바꿀 일이 있으면 Pi 관리자에게 요청한다.

6

규칙

담당

  • 내가 맡은 폴더만 고친다.
  • 다른 사람 폴더를 고쳐야 하면 담당자에게 먼저 말한다.
  • 누가 어디를 맡는지는 README의 "폴더별 담당" 표에 있다.

브랜치

  • 이름은 태그/파트/기능으로 짓는다.
  • 예: feature/pi/gateway-queue
  • main과 dev에는 직접 push하지 않는다.

커밋

  • 메시지는 타입(파트): 요약으로 쓴다.
  • 예: feat(pi): 대기 줄 추가
  • 계약을 바꾸면 메시지에 [contract]를 붙인다.

CI

  • PR을 올리면 바뀐 파트만 검사한다.
  • ci-ok가 초록불이어야 병합할 수 있다.
  • 계약 문서를 바꾸면 모든 파트를 검사한다.

테스트

  • tests/파트/ 폴더에 test_*.py로 넣는다.
  • 서비스 코드를 불러오지 말고 HTTP로 요청한다.
  • 모델이 필요한 테스트에는 model 표시를 붙인다.

계약

  • 파트 사이 데이터 형식은 구현 전에 docs/contracts/에 적는다.
  • 보내는 쪽과 받는 쪽이 둘 다 확인한다.
  • 배포는 받는 쪽부터 한다.

올리지 않는 파일

  • 비밀값: .env, config.h, 토큰
  • 큰 파일: 모델 가중치, 영상
  • 실행 중 생기는 것: pi/buffer/, 로그 파일

기록

  • 측정한 숫자에는 어느 커밋에서 쟀는지 같이 적는다.
  • 되돌리기 어려운 결정은 decisions.md에 남긴다.

내 PC에서 테스트

  • pi 폴더에서 CI용 설정으로 컨테이너를 띄운다.
  • 저장소 루트에서 pytest tests/pi tests/e2e를 돌린다.
  • 자세한 명령은 tests/README.md에 있다.
이 문서의 원본은 CLAUDE.md, README.md, pi/README.md다. 규칙이 바뀌면 같이 고친다.
